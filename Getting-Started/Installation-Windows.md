# Getting Started — Windows

This guide prepares a Windows computer to run the Verilog examples in TinyCore-8.

## 1. Install the tools

Install these tools:

- **Visual Studio Code** — code editor: https://code.visualstudio.com/
- **Icarus Verilog** — Verilog compiler and simulator: https://steveicarus.github.io/iverilog/
- **GTKWave** — waveform viewer: https://gtkwave.sourceforge.net/

During installation, make sure the tool executables are added to your Windows PATH, if the installer provides that option.

## 2. Verify the installation

Open PowerShell and run:

```powershell
iverilog -V
vvp -V
gtkwave --version
code --version
```

If a command is not recognised, check the installation folder and Windows PATH, then reopen PowerShell.

## 3. Clone the repository

```powershell
cd $HOME\Documents
git clone https://github.com/chetanrmaradi/TinyCore-8.git
cd TinyCore-8
code .
```

Git for Windows is required for the clone and version-control commands: https://git-scm.com/download/win

## 4. Compile and simulate an example

For example, to simulate the AND gate:

```powershell
cd Day-01
iverilog -o and_gate_sim and_gate.v tb_and_gate.v
vvp and_gate_sim
gtkwave and_gate.vcd
```

The testbench should print the input/output combinations and create a VCD waveform file.

## 5. Understanding the files

- `.v` — Verilog hardware design or testbench source.
- `.vcd` — Value Change Dump waveform generated by simulation.
- `*_sim` — locally generated simulation executable; do not commit it.

## Troubleshooting

- **File not found:** Run `pwd` and `dir *.v` to confirm you are in the folder containing the source files.
- **Command not recognised:** Verify installation and PATH, then restart PowerShell.
- **Compilation error:** Check the exact filename and module name; share the full compiler output when asking for help.

## Learning workflow

For each circuit: read the theory, inspect the Verilog, run its testbench, inspect the waveform, and compare the result with the expected truth table.

TinyCore-8 is a learning project. Verify each module before using it in a larger design.
