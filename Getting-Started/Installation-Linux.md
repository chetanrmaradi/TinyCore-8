# Getting Started — Linux

This guide gives a general setup path for Linux distributions. Package names and commands can vary by distribution.

## 1. Install the tools

On Debian or Ubuntu-based systems:

```bash
sudo apt update
sudo apt install git iverilog gtkwave
```

Install Visual Studio Code from: https://code.visualstudio.com/

## 2. Verify the tools

```bash
iverilog -V
vvp -V
gtkwave --version
git --version
```

## 3. Clone TinyCore-8

```bash
git clone https://github.com/chetanrmaradi/TinyCore-8.git
cd TinyCore-8
code .
```

## 4. Compile and simulate an example

```bash
cd Day-01
iverilog -o and_gate_sim and_gate.v tb_and_gate.v
vvp and_gate_sim
gtkwave and_gate.vcd
```

## File types

- `.v`: Verilog source and testbench files.
- `.vcd`: waveform data generated by simulation.
- `*_sim`: local compiled simulation executable; do not commit it.

## Troubleshooting

If a command is not found, install the missing package and check that its executable is available on PATH. If compilation fails, confirm the current directory and exact source filenames.
